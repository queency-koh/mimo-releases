# Mimo · downloads

Mimo is a tiny pixel cat that sits in the corner of your screen and keeps you company while you focus.

**Website:** https://hellomimo.vercel.app

## Download

- **Apple Silicon (M-series):** [Mimo-AppleSilicon.dmg](https://github.com/queency-koh/mimo-releases/releases/latest/download/Mimo-AppleSilicon.dmg)
- **Intel Mac:** [Mimo-Intel.dmg](https://github.com/queency-koh/mimo-releases/releases/latest/download/Mimo-Intel.dmg)
- **Windows 10/11 (64-bit):** [Mimo-Windows-Setup.exe](https://github.com/queency-koh/mimo-releases/releases/latest/download/Mimo-Windows-Setup.exe)

Not sure which Mac you have? Apple menu › About This Mac › Chip. Requires macOS 12 Monterey or later.

Open the .dmg and drag Mimo to Applications. The beta isn't signed yet. Mac: the first time, right-click Mimo and choose **Open**. Windows: if SmartScreen appears, click **More info › Run anyway**.

All versions and release notes: [Releases](https://github.com/queency-koh/mimo-releases/releases)
