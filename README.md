# Mimo · downloads

Mimo is a tiny pixel cat that sits in the corner of your Mac and keeps you company while you focus.

**Website:** https://hellomimo.vercel.app

## Download

- **Apple Silicon (M-series):** [Mimo-AppleSilicon.dmg](https://github.com/queency-koh/mimo-releases/releases/latest/download/Mimo-AppleSilicon.dmg)
- **Intel:** [Mimo-Intel.dmg](https://github.com/queency-koh/mimo-releases/releases/latest/download/Mimo-Intel.dmg)

Not sure which Mac you have? Apple menu › About This Mac › Chip. Requires macOS 12 Monterey or later.

Open the .dmg and drag Mimo to Applications. The beta isn't signed with an Apple Developer ID yet: the first time, right-click Mimo and choose **Open**.

All versions and release notes: [Releases](https://github.com/queency-koh/mimo-releases/releases)

This repository only hosts installers.
